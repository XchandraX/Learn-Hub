# 📖 Learning Hub

Web viewer untuk menampilkan dan menjalankan kode dari repositori GitHub — terinspirasi dari VSCode, dengan dukungan syntax highlighting, markdown rendering, dan code runner langsung di browser (Python, JavaScript, TypeScript, C/C++, Lua, SQL).

## ✨ Fitur

- 📂 File tree ala VSCode
- 💻 Syntax highlighting + line numbers
- 📝 Markdown render
- 🖼️ Viewer gambar, audio, video, PDF
- ▶️ Code runner: **Python, JavaScript, TypeScript, C/C++, Lua, SQL**
- 🌙 Dark / light mode
- 📱 Mobile friendly
- ⚡ Cache GitHub API biar cepat
